# Contributing to EPI Type

Thanks for your interest. Our typefaces are works in progress, and feedback is the most useful thing you can give.

## Ways to help

- **Report a bug**: wrong spacing, broken kerning, rendering issues, metadata errors.
- **Request glyphs or features**: missing characters, scripts, OpenType features, styles.
- **Send a pull request**: fixes to sources, build configuration or documentation.

## Before you start

1. Search the existing issues first.
2. For larger changes (new glyph sets, design changes), open an issue to discuss it before drawing anything. This avoids duplicated or unusable work.
3. Do not commit generated font files in pull requests. Binaries are produced by the build and published via releases.

## Pull requests

- Keep each pull request focused on one change.
- Describe what changed and why, with screenshots or proof images for design changes.
- Make sure the automated build and font checks pass.

## Licensing of contributions

By submitting a contribution you agree that it is released under the license of the repository you contribute to (see the `LICENSE`/`OFL.txt` file in that repository). Please only contribute work you have the right to share.

## Conduct

Be kind and constructive. Harassment and discrimination are not tolerated.
