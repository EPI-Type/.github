# EPI Type

**Forever in progress.** Half-cooked typefaces from the drawers of EPI Type, open for use, feedback and contributions.

EPI Type (formerly Space Type Lab) is a small type project based in Berlin. Our typefaces are works in progress: their level of development varies, and we like it that way. This organization holds the sources, builds and releases, one repository per typeface.

## How it works

- **One repository per typeface.** Each repo contains the font sources, the build configuration, the license and the released font files.
- **Releases** are tagged and carry ready-to-use font files. Grab them from the *Releases* section of a repository.
- **Something missing?** A character, a script, a style, a bug? Open an issue. Missing glyphs and extensions are very welcome requests.
- **Want to contribute?** See [CONTRIBUTING](../CONTRIBUTING.md).

## Typefaces

Repositories will appear here as typefaces are published. See [epitype.xyz](https://epitype.xyz/) for specimens and the full list.

## Licensing

Each repository states the license of its typeface in its own `LICENSE`/`OFL.txt` file. Please check the repository you are using.
